# 🎓 بوت مراقبة شواغر مواد جامعة اليرموك (YU Seat Checker Bot)

بوت تيليجرام ذكي وسريع لمراقبة شواغر المواد والشعب في **جامعة اليرموك (Yarmouk University)** بشكل مستمر على مدار الساعة، وإرسال إشعار فوري وتنبيه عاجل للطالب بمجرد قيام أي شخص بسحب المادة أو توفر مقعد شاغر! 🚀

---

## ✨ المميزات الرئيسية

- ⚡ **فحص دوري فائق السرعة بالخلفية**: فحص الشعب كل 3 ثوانٍ تلقائياً لاقتناص أي مقعد شاغر في أسرع وقت ممكن.
- 🚨 **تنبيه عاجل وفوري**: رسالة فورية صوتية تصلك على التيليجرام فور توفر أي شاغر مع تفاصيل المدرس والموعد والقاعة.

- 🔗 **زر سريع لبوابة التسجيل**: رابط مباشر يفتح نظام معلومات الطلبة (SIS) لتسجيل المادة فوراً قبل أن يأخذها طالب آخر.
- 📋 **إدارة كاملة للمواد**: استعراض، إيقاف مؤقت، استئناف، وحذف المواد المراقبة بسهولة عبر أزرار تفاعلية (Inline Buttons).
- 🔍 **فحص سريع**: إمكانية فحص أي شعبة لمرة واحدة بضغطة زر دون مراقبتها.
- 🧪 **الوضع التجريبي (Demo Mode)**: إمكانية تجربة البوت وتلقي التنبيهات فوراً للتأكد من عمله حتى خارج أوقات السحب والإضافة.
- 💾 **قاعدة بيانات SQLite محلية**: حفظ جميع المواد وحالاتها لضمان عدم فقدان أي بيانات عند إعادة تشغيل البوت.

---

## 🛠️ متطلبات التشغيل

- **Python 3.9** أو أحدث
- حساب تيليجرام لإنشاء البوت

## 🚀 طريقة التثبيت والتشغيل خطوة بخطوة

### 1️⃣ استخراج توكن البوت من تيليجرام
1. افتح تطبيق تيليجرام وابحث عن الحساب الرسمي [@BotFather](https://t.me/botfather).
2. أرسل له الأمر `/newbot`.
3. اكتب اسماً للبوت (مثال: `YU Course Checker`).
4. اكتب معرّفاً للبوت ينتهي بكلمة `bot` (مثال: `yu_courses_bot`).
5. سيعطيك `@BotFather` رمز التوكن (Token) بهذا الشكل:
   `7123456789:AAFxAbcDeFgHiJkLmNoPqRsTuVwXyZ12345`
   (احفظ هذا الرمز).

---

### 2️⃣ تثبيت المكتبات المطلوبة

افتح موجه الأوامر (Terminal أو PowerShell) في مجلد المشروع ونفّذ:

```bash
pip install -r requirements.txt
```

---

### 3️⃣ إعداد ملف التكوين `.env`

قم بإنشاء ملف باسم `.env` بجانب ملفات المشروع (أو انسخ ملف `.env.example` وعدله) وضع فيه التوكن الخاص بك:

```env
# ضع توكن البوت الذي حصلت عليه من BotFather هنا:
BOT_TOKEN=7123456789:AAFxAbcDeFgHiJkLmNoPqRsTuVwXyZ12345

# الفاصل الزمني بين كل فحص بالثواني (3 ثوانٍ للسرعة الفائقة)
CHECK_INTERVAL_SECONDS=3

# تفعيل الوضع التجريبي للتأكد من عمل التنبيهات (True / False)
DEMO_MODE=True
```

---

### 4️⃣ تشغيل البوت

نفّذ الأمر التالي:

```bash
python bot.py
```

ستظهر لك رسالة نجاح التشغيل:
```
============================================================
🚀 تم تشغيل بوت مراقبة شواغر جامعة اليرموك بنجاح!
⏱️ الفحص الدوري يعمل كل 45 ثانية.
🎯 وضع التشغيل: تجريبي (Demo Mode)
============================================================
```

## 📱 كيفية استخدام البوت من تيليجرام

1. ادخل إلى البوت الخاص بك على تيليجرام واضغط **Start** أو أرسل `/start`.
2. اضغط على **➕ إضافة مادة للمراقبة** (أو أرسل `/track`):
   - اكتب رمز المادة (مثل: `CS101` أو `101330`).
   - اكتب اسم المادة (مثل: `برمجة كينونية` أو أرسل `تخطي`).
   - اكتب رقم الشعبة (مثل: `1`).
3. سيقوم البوت بفحص الشعبة فوراً، وإذا كانت ممتلئة سيبدأ بمراقبتها بالخلفية كل 45 ثانية.
4. بمجرد توفر مقعد، ستصلك رسالة التنبيه العاجلة التالية:

```
🚨🚨 تنبيه عاجل: توفر مقعد شاغر! 🚨🚨

يا بطل، تم توفر مقعد الآن في مادتك المراقبة:

📚 المادة: برمجة كينونية (CS101)
🔢 الشعبة: 1
🪑 المقاعد المتاحة الآن: 🔥 1 مقعد شاغر! (المسجلين: 44/45)
👨‍🏫 المدرس: د. أحمد اليرموكي
⏰ الموعد: ن ر ث 10:00 - 11:00
🏛️ القاعة: مبنى الخوارزمي - قاعة 204

⚡ سارع فوراً بالدخول إلى نظام التسجيل (SIS) وسجل المادة قبل أن يأخذها طالب آخر!
```

## 📋 الأوامر المتاحة

| الأمر | الوظيفة |
|---|---|
| `/start` | فتح القائمة الرئيسية للبوت |
| `/track` | بدء معالج إضافة مادة وشعبة للمراقبة |
| `/list` | استعراض كل المواد المراقبة والتحكم بها (إيقاف/تشغيل/حذف/فحص) |
| `/check CS101 1` | فحص فوري وسريع لشعبة معينة لمرة واحدة |
| `/status` | عرض إحصائيات النظام وسرعة الفحص |
| `/help` | عرض دليل الاستخدام والمساعدة |
| `/cancel` | إلغاء العملية الحالية والعودة للقائمة |

---

## ⚙️ بنية الكود والمشروع

- `bot.py`: الكود الأساسي للبوت وإدارة المحادثات وجدولة الفحص الدوري (`JobQueue`).
- `scraper.py`: محرك فحص وحساب الشواغر والسعة لبوابة جامعة اليرموك.
- `database.py`: إدارة جداول SQLite لحفظ المواد وتتبع حالة الإشعارات.
- `config.py`: قراءة متغيرات البيئة وإعدادات الحماية والأمان.

## 🔒 ملاحظات هامة للأمان والتسجيل

- يتم تفعيل فترات انتظار ذكية (Jitter & Sleep) بين طلبات الفحص لحماية حسابك والـ IP من أي حظر من جدار حماية الجامعة.
- عندما تبدأ فترة السحب والإضافة الرسمية في جامعة اليرموك، قم بتعيين `DEMO_MODE=False` في ملف `.env` للربط الحي مع بوابة الجامعة.
- عندما تبدأ فترة السحب والإضافة الرسمية في جامعة اليرموك، قم بتعيين `DEMO_MODE=False` في ملف `.env` للربط الحي مع بوابة الجامعة.
